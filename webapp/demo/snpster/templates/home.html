How it works

From raw genotype file to an understandable report

Each processing step is designed to improve consistency, retain useful variants, and clearly communicate uncertainty.

01
⇧

Upload your data

Submit a supported raw genotype file from your consumer testing provider.

02
⧉

Standardize and impute

Variants are harmonized to a common genome build and missing genotypes are statistically imputed.

03
✓

Apply quality control

Low-confidence, ambiguous, and poorly supported variants are filtered before scoring.

◫

Built for transparency

More than a single risk number

Polygenic models can disagree. SNPster presents the models, supporting evaluation data, and uncertainty instead of hiding them behind one simplified score.
